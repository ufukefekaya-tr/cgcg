# Contributing

Use Node 24+, run syntax checks, tests and the production build. Add a synthetic
regression for parsing, generation, injection or profile behavior changes. State
supported controller semantics explicitly; never silently guess a dialect or
physical I/O mapping. Keep source recovery provenance accurate.

Submit original contributions under MIT OR Apache-2.0. Preserve dependency
notices. Do not contribute actual customer programs, database copies, credentials
or machine profiles that are not cleared for public redistribution.
